# Braids By Mimi: website

Spec website for **Braids By Mimi** (Mimi / Micheline, @braid_by_mimi), 6492 Landover Rd, Suite B, Room 6, Cheverly, MD 20785. Built by Couture House Co. (hello@couturehouse.co).

- Live preview (canonical): https://braids-by-mimi.netlify.app/
- Booking: on-site request builder (pre-written text to (469) 441-9208 + Netlify form `booking-request`). `/book` short link.

## Concept: "Neatness, Perfection" (her logo's tagline)
Her logo is gold + magenta pink on black with a crown, a pink bow, a comb and a double ring. The site lives in that world:
- **Palette:** ink #0E0A0C, plum #1D1318, cream #FBF6F1; gold #E2A94F (text on dark #F2C46A, on light #8C5F14); pink #EC4C88 (text on dark #F7679F, on light #B51F5A). All text pairs pass WCAG AA.
- **Type (self-hosted):** Bodoni Moda (display), Great Vibes (script accents, echoing her logo script), Figtree (body).
- **Scrollbars:** gold-to-pink thumb on ink; inner scrollers pink on ink.
- **Line art:** the Twelve:21 "gold line" style redrawn in her palette with her motifs (crown, bow, comb, double ring, heart). Kie.ai Nano Banana Pro, graded so every background pixel equals the page ink.

## Motion (CSS + IntersectionObserver + rAF; no libraries; off under prefers-reduced-motion; content visible without JS)
1. Hero line-art loop (poster is the LCP image; phones only load the phone file; paused off-screen; Save-Data gets posters) + four twinkling glints placed on the crown, ring and bow in the art's own coordinates.
2. **Braid rule** under every heading: a gold strand and a pink strand weave across, then tie off in a heart that fills in.
3. Foil sweep across each heading's pink words, once.
4. Emblem dividers: lines draw outward and the emblem turns with scroll.
5. Scroll progress bar (gold to pink) across the top.
6. Gallery: arch-shaped tiles in a staggered grid that rise in as you scroll; filters + keyboard lightbox.
7. Price finder / builder: price ticks in when you change style.

## Living line art (videos)
Four seamless 4.6 s loops (Kie.ai Kling 2.1 Pro from the approved stills, graded to the page ink, tail crossfaded into the head):
- `line-hero-desktop` (1600x890): she blinks, breathes, braids sway, crown and ring sparkle.
- `line-hero-phone` (720x654): the same clip cropped to head + crown + ring for portrait screens.
- `line-studio` (1600x890) and `line-studio-sq` (720x720): both women blink, braids and plant sway, sparkles twinkle. The braider's hands are locked to the first frame (Kling kept detaching a hand).
WebM (VP9) + MP4 (H.264), no audio, 0.4 to 0.85 MB each. Posters are frame 0 of each loop so poster-to-video is seamless. Phones load only phone files; loops pause off-screen and in background tabs; reduced motion and Save-Data get posters only.

## Owner portal demo (`owner.html`, also `/owner`, `/portal`, `/admin`)
Demo PIN 1234. Sample data in memory only (resets on reload, nothing sent). Mobile-first: bottom tabs on phones, sidebar on laptops.
- **Today:** greeting, booked today, deposits in, new website requests, last 7 days; Up next card (mark arrived, start, check out, text, ask for deposit); today's chair; requests preview; rebook-due list.
- **Requests:** the website booking-builder requests. Confirm a time (pre-fills style, day and time window, matches existing clients by phone), books it and opens a pre-written confirmation + deposit text; ask for a photo; decline with a polite reply.
- **Calendar:** week strip + laptop week grid (7 AM to 8 PM, color by style, dashed = deposit due, now line); day list on phones; tap any appointment for details, deposit received, arrived, start, check out, reschedule, no-show, cancel.
- **Clients:** search, VIP / Regular / New / Due-to-rebook filters; profile with visits, lifetime spend, next visit or rebook date, hair notes, braid-journey photos, history, book again.
- **Money:** 30-day revenue, average ticket, booked ahead, website share, 8-week revenue chart, top services, busiest days, rebook list with one-tap texts.
- **Menu & prices:** edit prices, "from" flag and show/hide per style (same menu data as the site, `assets/js/portal-data.js`).
- **Settings:** hours, deposit, buffer, walk-ins, reminder and thank-you/review texts, payment link, chair time per style.
- Checkout: balance after deposit, tip, payment method, optional thank-you text with her Google review link.
Going live: swap the DB object in `assets/js/portal.js` for Supabase (auth + tables), point the site form at it, add a payment link / Stripe for deposits, and Twilio for reminders. The UI does not change.

## Deploy (Netlify)
1. Push this folder to a new GitHub repo (e.g. `braids-by-mimi`).
2. Netlify: import from GitHub, no build command, publish directory `.`. Name the site `braids-by-mimi` so canonical URLs match.
3. Forms: Netlify detects `booking-request` on deploy. Turn on email notifications (Site settings, Forms).
4. Custom domain: replace `https://braids-by-mimi.netlify.app/` everywhere (canonical, og, JSON-LD, sitemap.xml, robots.txt, llms.txt).

## Device QA (Nov 4 2026)
Checked every page on iPhone SE (375x667), Android 360x780, iPhone 14 (390x664), iPhone 15 Pro Max, Pixel 7, phone landscape (844x390), iPad Mini portrait, iPad landscape, laptops 1280x720 / 1366x768 / 1440x900 / 1536x695 and 1920x1080:
no horizontal scroll, every tap target at least 44px, labels 12px or larger, no upscaled images, no console errors, and the hero's "Book your braids" button is on the first screen of every phone and laptop.
Layout rules: landscape screens (640px+ wide and wider than 7:5) get art-left / copy-right; portrait screens get the head-and-crown crop (`line-hero-phone`) above the copy. Short landscape screens get a slimmer header. Notched phones respect safe areas. Hover effects only run on devices that hover. The lightbox swipes left/right and swipes down to close.
